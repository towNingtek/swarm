大顆的星團＝EPIC（子 issue 越多越大），外圈綠色弧＝子 issue 完成比例；綠色閃環＝待你驗收；紅點閃＝裡面有 swarm 卡住。單擊 EPIC＝展開它的子 issue 與依賴（Shift＋點或圈選＝選取 EPIC）。
▶ 播放（空白鍵）＝重播所選天數內的開立、移動與關閉；再按一次暫停。
點行星＝選取；Shift／⌘＋點＝加減選；在空白處拖曳＝圈選多張；雙擊＝開 GitHub（雙擊中間的星核＝開這個 Project 的看板）；Esc＝取消選取。
拖曳行星＝沿著軌道換位置，可以把相關的 issue 排在一起；位置只存在這個瀏覽器。
往內／外拖到另一圈＝改狀態，會直接寫回 GitHub（只在「現在」可以改）；拖進中間的星核＝完成（會先問你，再關閉 issue）。EPIC 展開後，子 issue 也一樣可以拖。
⌥ Option（Windows／Linux：Alt）＋拖曳＝3D 翻轉（上下＝傾斜、左右＝旋轉）；翻轉時一切照常可以操作。0 或「100%」＝回到正面全景；3＝快速傾斜／放平。
縮放：滾輪／觸控板捏合／＋－鍵；平移：兩指滑動、按住空白鍵拖曳或右鍵拖曳；0＝回全景；F＝對焦選取；空白處雙擊＝放大。拉近後會顯示完整標題與負責人。
